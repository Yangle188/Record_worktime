**M1 验收清单**（PRD §13 中可在 M1 覆盖的条目）

- [x] #1 断网打卡可落库（未校准时以本地时间落库并标注 `local`）；幂等键 + 唯一索引保证不产生重复条目
- [x] #2 打卡成功后**必定**弹出结果卡片（`PunchResultCard`，浏览器实测通过）
- [x] #3 多段循环时长正确、跨 0 点归属开始日（`punchService.test.ts`、`businessDay.test.ts`）
- [x] #4 修改设备时间后打卡，仍以网络校准时间为准并展示偏差与时间来源（`clockService.test.ts` + 明细展示）
- [x] #7 定位被拒 / 超时仍可打卡，标注「未记录地点」（浏览器实测：`定位超时，未记录地点`，记录照常落库）
- [x] #9 导出 → 清空站点数据 → 导入，完整恢复（`backupService.test.ts` 覆盖导出 / 覆盖导入 / 合并去重）
- [x] #10 汇总数字与明细完全一致（`summarize.test.ts` 断言 `byDay` / `byPlace` / 逐条明细三者相等）

> 性能实测（本地 Chrome，`localhost`）：**点击 → 落库 20ms**（最坏情况：定位超时不再阻塞落库），满足 PRD §6「< 3s（含定位耗时）」。
